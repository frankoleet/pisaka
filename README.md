# pisaka

Сайт конспектов на Next.js App Router, TypeScript и Tailwind CSS.

## Запуск и проверки

Node.js 22.6+.

```sh
npm ci
npm run dev
npm run lint
npm test
npm run build
```

Production: `npm start`.

## Страницы

- `/` — главная, преимущества, этапы, фотографии и FAQ.
- `/order` — заявка и оплата.
- `/orders` — история в браузере.
- `POST /api/orders` — серверная отправка в Telegram.

## Telegram на Vercel

В Settings → Environment Variables задайте для Production:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather, тип Secret.
- `TELEGRAM_CHAT_IDS` — числовые ID получателей через запятую: личные чаты, группа или оба варианта.

Не добавляйте префикс NEXT_PUBLIC. После изменения переменных нужен новый деплой. Для локальной разработки эти значения можно задать в .env.local (он исключён из Git).

Получатели личных сообщений должны запустить бота через /start. В группе бот должен быть участником с разрешением отправлять сообщения.

При нажатии «Я оплатил(а)» сервер проверяет поля, заново рассчитывает цену и отправляет заявку во все настроенные чаты. Сообщение содержит тему, имя, WhatsApp со ссылкой, объём, срочность, сумму, комментарий и номер. Нажатие кнопки не подтверждает банковский перевод — в сообщении указана необходимость ручной проверки.

Статус «Отправлена» и история появляются только после подтверждения Telegram для всех получателей. При ошибке данные формы остаются для повторной попытки. Ошибка localStorage после успешной отправки показывает предупреждение и не требует повторять отправку.

Защита от двойного клика работает на клиенте. Сервер хранит результат и список получивших сообщение чатов один час в памяти текущего экземпляра: при повторе отправляет только недоставленные сообщения. Базовый лимит — 10 запросов в минуту с одного IP на экземпляр. Эти меры НЕ гарантируют отсутствие дублей между разными экземплярами Vercel или после тайм-аута Telegram. Для строгой идемпотентности и общего лимита нужна постоянная база/Redis. Номер заказа пока создаётся браузером и не гарантирует глобальную уникальность.

## Настройки и QR

В src/lib/config.ts: 45 сом/лист, срочность ×2, объём 1–100, контакты, условия и фотографии.

Для QR положите изображение в public/payment-qr.jpg и задайте:

```ts
export const QR_IMAGE_URL = "/payment-qr.jpg";
```

Также заполните paymentRecipient, telegram и whatsapp. Кнопка подтверждения доступна через 30 секунд после перехода к оплате.

## История

localStorage хранит только номер, дату, тему, объём, срочность, сумму и статус; телефон, имя и комментарий не сохраняются в браузерную историю. Очистка данных сайта удаляет историю. Старые демо-заявки остаются явно помечены как демо; автоматически в Telegram они не отправляются.

Серверной базы заказов пока нет. Полученные сообщения хранятся в Telegram.

## Оформление и публикация

Стили: src/app/pisaka.css. Локальный Manrope: src/app/fonts, лицензия OFL рядом. Фото работ: public/works. Vercel Analytics подключён в общем layout.

Исходники находятся в корне репозитория. На Vercel выберите Next.js и сборку npm run build. node_modules, .next, .vercel и .env* исключены из Git.

После деплоя создайте тестовую заявку и проверьте доставку всем получателям. Перед рабочим запуском добавьте QR и контакты, подтвердите тексты о способе изготовления и сроках.

## Чек к оплате

Перед отправкой клиент обязан выбрать фото или скриншот чека (JPG, PNG, WebP, до 3 МБ). Кнопка доступна только после выбора файла и окончания 30-секундного таймера. Можно заменить или удалить изображение; при удалении кнопка снова блокируется.

API принимает multipart/form-data с полями order (JSON) и receipt (изображение), проверяет размер, тип и сигнатуру файла. Чек передаётся в Telegram через sendDocument без сжатия, отдельным сообщением с номером заказа. Заказ считается отправленным только после доставки текста и чека всем получателям. При повторе в том же экземпляре сервера повторяются только недоставленные части.

Файл не сохраняется в localStorage, public или серверной базе. После доставки он остаётся в Telegram. Сам факт загрузки изображения не подтверждает платёж: перевод проверяется вручную.
